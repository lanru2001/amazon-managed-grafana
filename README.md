## Amazon Managed Grafana

Amazon Managed Grafana(AMG) is a fully managed and secure data visualization service that can be use to instantly query, correlate, and visualize operational metrics, logs, and traces from multiple sources. 

It makes it easy to deploy, operate, and scale Grafana, a widely deployed data visualization tool that is popular for its extensible data support. With AMG, we create logically isolated Grafana servers called workspaces. Then, we can create Grafana dashboards and visualizations to analyze your metrics, logs, and traces without having to build, package, or deploy any hardware to run your Grafana servers.

AMG manages the provisioning, setup, scaling, and maintenance of your logical Grafana servers so that we don't have to do these tasks ourselves. Amazon Managed Grafana also provides built-in security features for compliance with corporate governance requirements, including single sign-on, data access control, and audit reporting.
